        self._update_from_netro()
    except self.StopThread:

2. Use `logger.exception()` which automatically captures full traceback at ERROR level
3. Remove bare tuple syntax `(Exception,)` - use `Exception:` instead
4. Keep thread running after errors by not re-raising general exceptions
